# Modelo de nota de decisão

Copie para `decisoes/AAAA-MM-DD-assunto.md`, preencha e ligue em [[Decisoes-indice]].

```markdown
---
tipo: decisao
data: AAAA-MM-DD
atualizado: AAAA-MM-DD
tags: [cerebro, decisao]
---

# Título curto da decisão

**Data:** AAAA-MM-DD  ·  **Quem decidiu:** dono / assistente (qual regra aplicou)

O que foi decidido, em 2–5 linhas, com as palavras do dono entre aspas quando houver.

**Por quê:** o motivo (evidência, custo, risco).
**Como aplicar:** o que muda no trabalho, que arquivos e comandos.
**Estado:** feito / pendente / revertido (com data).

Relacionadas: [[outra-nota]]
```

Regras: nada de senha, chave, número de conta, e-mail ou dado pessoal. Datas absolutas (nunca "ontem"). Se divergir do código, o código está certo.
